# scripts/

سكربتات إعداد البيئة المحلية، توليد بيانات تجريبية (Seed Data)، ونسخ احتياطي.
أمثلة مقترحة (تُضاف عند الحاجة الفعلية في المرحلة 0):
- `seed_demo_company.py` — إنشاء شركة/فرع/مستودع تجريبي كامل لبيئة التطوير
- `run_migrations.sh` — تشغيل Alembic على كل قواعد البيانات
- `backup_db.sh` — نسخ احتياطي يدوي محلي
