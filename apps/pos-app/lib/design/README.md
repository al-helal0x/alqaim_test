# نظام تصميم pos-app (Flutter محلي مستقل)

**القرار محسوم (مهمة #13، أول ساعتين):** `packages/ui-kit` مكتوب React/TSX
للويب فقط ولا توجد طريقة تقنية لاستهلاكه من Flutter (لا Flutter يفهم TSX،
ولا يوجد أي جسر توليد كود مطروح في Blueprint). لذلك `apps/pos-app` **لا
ينتظر** أي ترحيل لـ `ui-kit` — يملك نظام تصميمه الخاص بالكامل هنا، وهذا
اختيار دائم للمنتج وليس حلاً مؤقتاً.

## البنية
- `tokens.dart` — ألوان/مسافات/زوايا/أحجام لمس خام. القيم محافظة عمداً
  (لا هوية بصرية "رسمية" موثَّقة لـ AlQaim حتى الآن) — قابلة للتبديل لاحقاً
  دون أثر على الشاشات لأن كل شيء يمرّ من هنا فقط.
- `theme.dart` — يبني `ThemeData` واحد من الرموز أعلاه.
- `widgets/` — مكوّنات قابلة لإعادة الاستخدام: `PosButton`, `PosTextField`,
  `PosScaffold`, `MoneyText`, `PosEmptyState`, `PosStatusBadge`.

## القاعدة
أي شاشة POS جديدة تستخدم هذه المكوّنات فقط — لا ألوان/مسافات حرفية مباشرة
داخل ملفات `features/`. أي حاجة لمكوّن جديد تُضاف هنا أولاً.
