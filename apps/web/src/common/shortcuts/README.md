# اختصارات لوحة المفاتيح — القائم (AlQaim)

> يوثّق هذا الملف نظام الاختصارات المُضاف في `apps/web/src/common/shortcuts/`،
> ومنطق التصميم وراءه، وكيفية تفعيله في شاشة إضافية.

## لماذا هذا التصميم تحديداً؟

طُلب الاستفادة من اختصارات **برنامج الأمين للمحاسبة** وبرامج المحاسبة
العالمية. لم نجد جدول اختصارات رسمياً منشوراً من الأمين نفسها يوثّق مفاتيحه
حرفياً — لكن هذا **النمط موثَّق وشائع** عبر كل هذا الجيل من برامج المحاسبة
العربية (الأمين وأمثاله، المبنية على تقليد Windows Desktop الكلاسيكي/Delphi):

| المفتاح | الوظيفة الشائعة في هذا الجيل من البرامج |
|---|---|
| F2 | سجل/فاتورة/قيد جديد |
| F3 | بحث |
| F5 | حفظ |
| F6 | طباعة |
| F8 | حذف |
| F9 | ترحيل |
| Insert | سطر جديد داخل جدول الأصناف/الأسطر |
| Esc | إلغاء / إغلاق الفورمة |

على الويب، أرقام F هذه **محجوزة فعلياً من المتصفح** نفسه:

| مفتاح الأمين | ماذا يفعل في متصفح ويب فعلياً |
|---|---|
| F1 | يفتح مساعدة المتصفح |
| F3 | يفتح بحث الصفحة (Find in page) |
| F5 | يعيد تحميل الصفحة (يفقد أي بيانات غير محفوظة) |
| F12 | يفتح أدوات المطوّر |

الحل هنا **طبقتان معاً**:

**1) طبقة "توافق الأمين" — نفس الرقم، خلف `Alt` بدل الاعتماد على `F` وحده:**

| الأمين | هنا | لماذا |
|---|---|---|
| F2 (سجل جديد) | `Alt+2` | نفس الرقم لنقل الذاكرة العضلية، بدون تصادم المتصفح |
| F3 (بحث) | `Alt+3` | يفتح نفس لوحة الانتقال السريع (Ctrl+K) |
| F5 (حفظ) | `Alt+5` | |
| F6 (طباعة) | `Alt+6` | بلا معالِج مسجَّل من الصفحة، يستدعي طباعة المتصفح مباشرة |
| F8 (حذف) | `Alt+8` | |
| F9 (ترحيل) | `Alt+9` | يسقط تلقائياً لفعل "حفظ" إن كانت الشاشة لا تفرّق بينهما |
| Insert | `Insert` | **مطابق حرفياً** — غير محجوز من المتصفح أصلاً |
| Esc | `Esc` | **مطابق حرفياً** — غير محجوز من المتصفح أصلاً |

**2) طبقة حديثة إضافية** (لا تلغي الأولى، بل تتعايش معها) تغطي ما لا
تقدّمه أرقام F أصلاً — التنقّل المباشر لأي شاشة والبحث الشامل:

| فكرة الأمين | المكافئ هنا | لماذا |
|---|---|---|
| — (لا مكافئ في الأمين) | `G` ثم حرف (أسلوب Gmail/Linear/GitHub) للانتقال لأي شاشة | الأمين تطبيق شاشات ثابتة قليلة العدد، بينما هذا النظام يضم 20+ شاشة تحتاج انتقالاً سريعاً بينها |
| — | `Ctrl/⌘+K` لوحة انتقال/بحث شامل | نفس ما تقدّمه برامج محاسبة حديثة (QuickBooks/Xero) |
| — | `Ctrl/⌘+N` (مرادف لـ Alt+2) | القياسي عالمياً (Word/Excel/كل تطبيقات المكتب) لمن يأتي من خلفية غير الأمين |
| — | `Ctrl/⌘+S` (مرادف لـ Alt+5) | القياسي عالمياً |
| — | `Ctrl/⌘+Delete` لحذف سطر بالجدول (لا سجل كامل) | Delete المفرد داخل حقل الجدول يُترك لحذف نص الحقل نفسه |
| — | `Ctrl/⌘+Enter` لترحيل القيد من أي مكان بالجدول | أسلوب Excel/Google Sheets للإدخال متعدد الأسطر |
| — | `?` قائمة كل الاختصارات | قياسي في Gmail/Linear/GitHub/Slack |

باختصار: **من جاء من الأمين يستخدم Alt+2/3/5/6/8/9 وInsert وEsc فوراً بلا
تعلّم جديد تقريباً**، ومن اعتاد أدوات الويب الحديثة يستخدم Ctrl+K وCtrl+N
وG+حرف بنفس الراحة — كلاهما يعملان معاً في آن واحد.

## البنية

```
apps/web/src/common/shortcuts/
├── registry.ts              # مصدر الحقيقة الوحيد: كل شاشة + حرف G-انتقالها
├── shortcut-context.tsx     # React Context لتسجيل معالِجات "جديد/حفظ/إلغاء"
├── use-global-shortcuts.ts  # المستمع الوحيد على window (يُركَّب مرة واحدة)
├── use-page-shortcuts.ts    # Hook تستخدمه أي صفحة للاشتراك بالإجراءات العامة
├── use-grid-shortcuts.ts    # سلوك Insert/Ctrl+Delete/Ctrl+Enter داخل جدول واحد
├── command-palette.tsx      # واجهة Ctrl/⌘+K
└── shortcuts-help.tsx       # واجهة "؟" (كل الاختصارات مجمّعة)
```

كلها مُركَّبة مرة واحدة في `common/app-shell.tsx` (الذي يغلّف كل صفحات لوحة
التحكم عبر `app/(dashboard)/layout.tsx`) — أي صفحة تُضاف تحت هذا التخطيط
تحصل على الاختصارات العامة والـ`?` والـCtrl+K تلقائياً بلا أي كود إضافي.

## كيف تُفعِّل اختصارات "جديد/حفظ/إلغاء" (وAlt+2/5/9 المرادفة) في صفحة جديدة

مثال حقيقي مطبَّق في `accounting/journal-entries/page.tsx`:

```tsx
import { usePageShortcuts } from "@/common/shortcuts/use-page-shortcuts";

// داخل مكوّن الصفحة:
usePageShortcuts({
  onNew: () => setShowForm(true),
  onCancel: showForm ? () => setShowForm(false) : undefined,
});
```

وداخل الفورمة نفسها (مكوّن منفصل، يُسجَّل ويُلغى تلقائياً مع تركيبه/فكّه):

```tsx
const formRef = useRef<HTMLFormElement>(null);
usePageShortcuts({
  onSave: () => formRef.current?.requestSubmit(),   // Ctrl/⌘+S وAlt+5 معاً
  onPost: () => formRef.current?.requestSubmit(),   // Alt+9 (اختياري — إن حُذف يسقط لـ onSave تلقائياً)
});

return <form ref={formRef} onSubmit={handleSubmit}>...</form>;
```

`onDelete` و`onPrint` متاحان بنفس الطريقة (Alt+8 وAlt+6 على الترتيب) —
غير مستخدَمين في مثال القيود اليومية لأنها لا تدعم حذف/طباعة سجل مفرد بعد.

لا حاجة لأي تنظيف يدوي — الـ Hook يُلغي التسجيل تلقائياً عند مغادرة الصفحة
أو إغلاق الفورمة، فلا يبقى معالِج شاشة سابقة فعّالاً بالخطأ.

## كيف تُفعِّل سلوك الجدول (Insert/Ctrl+Delete/Ctrl+Enter)

طبِّقه على عنصر الحاوية المحيط بأسطر الجدول (لا على النافذة كلها)، ويحتاج كل
سطر خاصية `data-grid-row={index}` ليعرف الحذف أي سطر يستهدف:

```tsx
import { handleGridKeyDown } from "@/common/shortcuts/use-grid-shortcuts";

<div
  onKeyDown={(e) =>
    handleGridKeyDown(e, {
      addRow: addLine,
      removeRow: removeLine,
      submit: () => formRef.current?.requestSubmit(),
      currentRowCount: lines.length,
      minRows: 2,
    })
  }
>
  {lines.map((line, i) => (
    <div key={i} data-grid-row={i}>...</div>
  ))}
</div>
```

## الشاشات المتبقية

النمط مطبَّق كمثال كامل على شاشة **القيود اليومية** فقط (`Ctrl+N` / `Esc` /
`Ctrl+S` على مستوى الصفحة، و`Insert`/`Ctrl+Delete`/`Ctrl+Enter` داخل جدول
الأسطر). التنقّل العام (`G` + حرف، `Ctrl/⌘+K`، `?`) يعمل بالفعل على **كل**
الشاشات الـ22 المذكورة في `registry.ts` دون أي تعديل إضافي، لأنه مُركَّب
مركزياً في `app-shell.tsx`.

لتفعيل `Ctrl+N`/`Esc`/`Ctrl+S` في باقي الشاشات (المبيعات، المشتريات،
المدفوعات...)، أضِف استدعاء `usePageShortcuts(...)` بنفس النمط أعلاه —
معظمها يتّبع نفس شكل "زر يفتح فورمة داخل الصفحة" الموجود في journal-entries،
فالنقل تلقائي تقريباً.

## ⚠️ قاعدة صيانة مهمة

`NAV_SHORTCUTS` في `registry.ts` مقصود أن يبقى **مطابقاً 1:1** لبنية
`NAV_SECTIONS` في `app-shell.tsx` (نفس الروابط، بنفس الترتيب تقريباً). أي
إضافة/حذف/تعديل رابط في القائمة الجانبية يجب أن يُقابله تحديث في
`registry.ts`، وإلا ستفقد الشاشة الجديدة اختصار الانتقال السريع إليها.
