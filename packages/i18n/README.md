# packages/i18n

قواميس الترجمة المشتركة بين كل التطبيقات (ar/en) — دعم RTL/LTR كامل
(معيار تسليم العضو 7 — القسم 13.2).

## الحالة (محدَّثة)
- ✅ قاموسان حقيقيان (`ar/common.json`, `en/common.json`) بمفاتيح شريط التنقّل الكامل + أفعال شائعة + حالات تحميل/فراغ.
- ✅ `t(key, locale?)` مع سقوط تلقائي للعربية ثم للمفتاح نفسه — لا نص مكسور أبداً.
- ✅ **تكامل فعلي مُتحقَّق منه**، وليس مجرد بنية خاملة: `app-shell.tsx` (شريط التنقّل بالكامل) و`login`/`register`/`onboarding` (اسم العلامة التجارية) تستهلك `t()` فعلياً الآن.
- ❌ لا تبديل لغة وقت التشغيل بعد (`dir="rtl"` لا يزال ثابتاً في `layout.tsx`؛ قاموس `en/` جاهز لكن غير مفعَّل UI). بقية الصفحات (27) لم تُحوَّل لـ `t()` بعد — نطاق كبير مؤجَّل عمداً.
