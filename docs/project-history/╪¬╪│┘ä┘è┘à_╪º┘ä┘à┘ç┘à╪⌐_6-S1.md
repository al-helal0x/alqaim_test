# Task #6-S1 — Event Bus Lifecycle & DI — ملخص التنفيذ

## الفكرة المعمارية
`EventBus` لم يعد يُنشأ كـ Singleton عالمي عند وقت الاستيراد. الملكية أصبحت
صريحة عبر **Context-scoped Dependency Injection** (`contextvars`):

```
platform_core/event_bus.py
  EventBus              — نفس الصنف بالضبط (subscribe/publish لم يتغيّرا)
  set_event_bus(bus)    — يربط EventBus بالسياق الحالي (Application أو اختبار)
  reset_event_bus(tok)  — يُلغي الربط عند نهاية السياق
  get_event_bus()       — المُزوِّد الرسمي؛ RuntimeError صريح إن لم يُربَط شيء
  event_bus             — Facade خفيف يُفوِّض subscribe/publish إلى get_event_bus()
```

`event_bus` يبقى قابلاً للاستيراد المباشر (`from platform_core.event_bus
import event_bus`) — **لم يُعدَّل أي ملف داخل `modules/*`**. الفرق أن هذا
الاسم الآن يُفوِّض إلى نسخة مختلفة فعلياً حسب السياق، بدل التراكم على كائن
واحد ثابت طوال عمر عملية pytest.

## لماذا هذا وليس `EventBus.reset()`
`reset()` يبقي المشكلة الجذرية: كائن عالمي واحد يُشترَك بين كل شيء، ومن
يستدعي `reset()` ومتى قرار هش يعتمد على تذكّر كل مطوّر فعله. هنا: كل سياق
(تطبيق أو اختبار) **يملك** نسخته الخاصة من البداية — لا حاجة لتنظيف كائن
مشترك لأنه لا يوجد كائن مشترك أصلاً.

## main.py — تغيير الـ Wiring فقط
الاشتراكات الستة (`PaymentRecorded`، `SalesInvoiceCreated`، حلقتا الويبهوك
والتدقيق، حلقة الإشعارات) انتقلت من التنفيذ المباشر عند الاستيراد إلى دالة
`wire_event_subscriptions(bus)` تُستدعى مرة واحدة داخل `lifespan` على
EventBus جديد (Application-scoped). **تم التحقق آلياً (diff) أن مجموعة
أسماء الأحداث وترتيبها مطابقان حرفياً للنسخة المرجعية** — لا إضافة ولا حذف
ولا تعديل على أي اشتراك تجاري، اسم حدث، أو شكل payload.

## conftest.py — عزل تلقائي لكل اختبار
```python
@pytest_asyncio.fixture(autouse=True)
async def _isolated_event_bus():
    bus = EventBus()
    token = set_event_bus(bus)
    try:
        yield bus
    finally:
        reset_event_bus(token)
```
`autouse=True` عمداً: العزل خاصية بيئة الاختبار نفسها، لا يعتمد على أن
يطلبه كل اختبار صراحة. `db_session` fixture لم يُمَس (نفس استيراد
`outbox_models`، خارج حدود هذه المهمة).

## الملفات المسلَّمة
- `apps/core-api/platform_core/event_bus.py` — مُعدَّل (الهدف الأساسي)
- `apps/core-api/main.py` — مُعدَّل (آلية Wiring فقط؛ هذا الملف يستبدل
  `main.py` **الحقيقي** في الشجرة الرئيسية — وليس نسخة منفصلة)

  (يثبت معياري القبول #1 و#3 مباشرة)
- `test_sales_and_pos.py`, `test_redis_event_bridge.py`,
  `outbox_models.py.مرجع_للقراءة_فقط` — بلا أي تعديل (تحقّق diff)، مُرفَقة
  للاكتمال فقط

## ما لم يُلمَس (وفق ADR-002 وحدود المهمة)
Event Envelope · Outbox Contract · Redis Contract · أي اسم أو payload حدث ·
أي ملف داخل `modules/sales`, `modules/accounting`, `modules/workflow` ·
`apps/ai-platform` · Database Schema · قواعد العمل.

## ملاحظة تحقق
لم تتوفر شجرة `modules/*` الكاملة ضمن هذه الحزمة (مقصود — خارج نطاقها)،
لذا لا يمكن تشغيل `pytest` الفعلي على `test_sales_and_pos.py` هنا. تم
التحقق بدلاً من ذلك عبر:
1. اختبار وحدة مستقل لآلية `event_bus.py` نفسها (DI عبر contextvars) —
   ✅ عزل، ترتيب، رفع RuntimeError عند غياب سياق.
2. `diff` آلي مؤكِّد لتطابق كل اشتراك تجاري بين `main.py` الجديد والنسخة
   المرجعية.
3. `py_compile` / `ast.parse` لكل الملفات المُسلَّمة.
